# DW2 · Persona Atelier

**DW2 · 人设工坊** · TauriTavern Persona 原生人设管理页视觉扩展  
**S.A. · DW2**

与 [DW2 · Character Gallery](https://github.com/dw2devil1024-creator/DW2-Character-Gallery) 同属 DW2 系列，但**独立安装、独立设置、独立更新**。

## 安装

在 TauriTavern 的「安装扩展」粘贴以下 Git 仓库 URL：

```text
https://github.com/dw2devil1024-creator/DW2-Persona-Atelier
```

安装后刷新酒馆。进入「扩展」设置，展开 **DW2 · Persona Atelier**，可以开启/关闭人设工坊美化，并点击「打开人设管理」回到原生人设页面。默认开启美化。

## v1.0.0 · 人设工坊初版

- 美化 **TT 原生用户设定管理**（`#PersonaManagement`），不覆盖右侧角色档案馆。
- 编辑风格：冰蓝灰 / 乳白 / 雾粉的轻量暗色杂志排版；紧凑搜索与分页栏；人设卡三列排列、3:4 封面、细腻的选中/默认标记。
- 优化当前人设编辑区的名称、工具栏、描述框、注入位置、角色/聊天绑定及全局设置的视觉层级。
- 保留 TT **原生节点与交互**：人设选择、新建、改名、复制、更换头像、删除、搜索、A-Z 排序、分页、绑定、Token 计数、备份与恢复。
- 扩展设置页有独立折叠入口，提供外观开关、前往人设管理、手动 Git 更新检测及更新后刷新功能。
- 样式以 `body.dw2pa-active #PersonaManagement` 限定作用范围，使用本地偏好 `dw2pa:enabled:v1` 控制开启。关闭外观恢复原生样式；不修改任何用户人设数据。
- 不插手 TT 的 persona 渲染过程与分页回调，不重建卡片，不拦截点击，不修改人设的存储键。
- 不依赖额外运行时库；需要 TT 的原生扩展加载机制。

## 兼容与测试

该版本基于 TauriTavern 官方开源 `src/index.html`、`src/style.css`、`src/scripts/personas.js` 和手机布局 CSS 的结构核对。**代码检查不等于真机测试**，以下待在手机端验收：

- iPhone/Android/PC 的网格排布、裁切、文本溢出和弹出菜单。
- 原生列表/网格按钮、默认人设及当前人设高亮。
- 人设选择、编辑描述与自动保存、绑定到角色/聊天、切换后同步。
- 搜索、排序、换页/每页条数、头像上传/替换、备份与恢复。
- 在扩展设置中禁用/重新启用人设工坊时恢复原生外观。
- 与 DW2 · Character Gallery / DW2 · Story Archive 同时启用的样式隔离。

> 本项目只负责“如何显示”，不负责“如何存储”。修改前建议使用 TT 原生的备份功能备份人设。

## v1.0.1 · 工具收纳与双视图

- 在页面标题旁新增 `ATELIER VIEW / NATIVE VIEW`，一键切换美化与 TT 原生外观，并与扩展设置开关同步。
- 将 TT 原生使用统计、备份、恢复、创建、网格/列表切换按钮原节点收纳进「工具与管理」折叠区，保留原生点击事件。搜索、A-Z 排序与分页保持常驻。
- 在当前人设姓名旁新增「人设操作」按钮，默认收起原生六项操作，需要时展开。
- 收起状态记于插件私有本地设置。切到原生视图或停用插件时，所有移动过的工具节点恢复原位，并移除新增的临时控件。
- 修正初版样式可能强行显示未绑定人设的锁图标的问题；锁定状态仍由 TT 控制。

**待真机验证：** 三种展开/收起、切换到原生后操作按钮归位、从原生切回、打开角色绑定/切换默认人设、iPhone 窄屏工具栏。
